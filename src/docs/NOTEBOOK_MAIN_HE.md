## תא 4 (Code) - יבואים + טעינת `yolo26m.pt`

**מטרה:** יבואי ליבה חד-פעמיים ובניית מודל YOLO26 לשימוש חוזר.

**תוכן טיפוסי:**

```python
import time
import numpy as np
import pandas as pd
import cv2
import matplotlib.pyplot as plt
from pathlib import Path
from ultralytics import YOLO

MODEL_PATH = Path("yolo26m.pt")   # לצד המחברת בשורש הריפו
model = YOLO(str(MODEL_PATH))
print("Model loaded:", MODEL_PATH.name, "-", len(model.names), "classes")
```

**מדוע:** טעינת מודל אחת בכל מחברת. Ultralytics מוצא את IR של OpenVINO
אוטומטית ליד ה-`.pt` אם קיים ומעדיף אותו על CPU.

**פלט צפוי:** שורה בסגנון `Model loaded: yolo26m.pt - 80 classes`.

**כיוונונים:**

- אם אתה רוצה גודל היסק שונה, קבע `IMG_SIZE = 512` (מהיר) או `960`
  (חד) והעבר `imgsz=IMG_SIZE` לכל קריאת `.predict()` בהמשך.
- אם אתה על GPU, הגדר `RTCV_DEVICE=0` לפני הפעלת ה-kernel, או העבר
  `device=0` ל-`.predict()`.

## תא 17 (Code) - דגימה + כתיבת CSV

**מטרה:** ללוש את הצינור לחלון קצר וללכוד את היסטוריית הספירות
בטבלה.

**תוכן טיפוסי:**

```python
import csv
from datetime import datetime, timezone

DURATION_SEC = 120       # כמה זמן לדגום סה"כ
INTERVAL_SEC = 5         # תדר דגימה בשניות
OUT_CSV = Path("data/footfall_single_cam.csv")
OUT_CSV.parent.mkdir(parents=True, exist_ok=True)

url = resolve_source(CAM["kind"], CAM)
rows = []
end_at = time.time() + DURATION_SEC
while time.time() < end_at:
    frame = grab_frame(url, timeout=8.0)
    if frame is None:
        continue
    res = model.predict(frame, imgsz=640, conf=0.25, verbose=False)[0]
    n_person = int(sum(1 for c in res.boxes.cls if int(c) == 0))
    rows.append({
        "ts": datetime.now(timezone.utc).isoformat(timespec="seconds"),
        "cam_id": CAM_ID,
        "n_person": n_person,
    })
    print(f"{rows[-1]['ts']}  {n_person:3d} persons")
    time.sleep(max(0, INTERVAL_SEC - 0.5))

with OUT_CSV.open("w", newline="") as f:
    w = csv.DictWriter(f, fieldnames=["ts", "cam_id", "n_person"])
    w.writeheader()
    w.writerows(rows)
print(f"Wrote {len(rows)} rows -> {OUT_CSV}")
```

**מדוע:** מדגים את המקטע העיוני של הצינור בלי לסבך אותו במעקב, פוזה או
לוחיות. `n_person` הוא הגודל הבסיסי ביותר; כל שאר השכבות בונות עליו.

**פלט צפוי:** שורה פר דגימה עם חותמת זמן ומספר אנשים, ואז שורת סיכום
בסגנון `Wrote 24 rows -> data/footfall_single_cam.csv`.

**כיוונונים:**

- `DURATION_SEC` - אורך החלון. השאר קצר בזמן שחקירה; הגדל לאחר מכן.
- `INTERVAL_SEC` - צפיפות הדגימות. תדר גבוה = יותר עלות CPU.
- `OUT_CSV` - שנה נתיב אם אתה רוצה קובץ פר מצלמה.
